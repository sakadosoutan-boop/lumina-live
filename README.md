# Lumina Live

バンドの生演奏と音源再生の両方に対応する、ローカル動作のVJアプリです。操作画面と投影画面を分け、A/Bの映像とCの重ね映像を合成します。

## 起動

**ブラウザー版：[Lumina Liveを開く](https://sakadosoutan-boop.github.io/lumina-live/)**。Windows／ChromebookのChromeで利用できます。内蔵映像とデモ歌詞は、そのまま「再生」で試せます。[ブラウザー版の使い方](docs/browser.md)

- **Windows**：プロジェクト直下の `Lumina-Live.exe` を起動します。動画ライブラリの `assets` フォルダーはEXEと同じ階層に配置します。`scripts/start-windows.cmd` も使えます。配布用EXEの控えは `release` にあります。
- **Chromebook**：`release/Lumina-Live-offline.html` をChromeで開きます。「取り込む」から手元の動画を選択します。素材はブラウザーのローカル保存領域に保存されます。HTML本体には96種類の生成映像を内蔵しています。
- **開発環境**：`npm ci` → `npm run build` → `npm run serve`。表示された `http://127.0.0.1:4173/` を開きます。Windowsのデスクトップ版は `npm start`。

詳しい配置・起動方法は [起動ガイド](docs/launch.md) を参照してください。

素材を取り込まずに使える96種類の生成映像と、6種類の映像プリセットを内蔵しています。「映像プリセット」でオープニング／ロック／サビ／静かな曲／グリッチ／エンディングを選ぶと、3レイヤーの組み合わせ・動き・効果を即時に適用します。歌詞、曲の時刻、マスター音量は保持します。自動VJと予約中の切り替えは解除します。

GitHubには単独で開ける [HTML本体](web/Lumina-Live.html)、ソース、テスト、素材取得スクリプトと、公開配布可能な125本の軽量動画を保存しています。公開動画は `docs/assets/library` にあります。全品質の原本や配布条件を確認できていない素材はローカルの `assets` に保持します。

## 最初のリハーサル

1. HDMI出力を「拡張表示」、プロジェクター側を1920×1080にします。内部描画はまず1280×720／30 FPSから始め、実機の負荷を見て調整します。
2. 「セットを開く」で `examples/Demo-Session.lumina.json` を読み込むか、自分の曲を追加します。デモ歌詞は動作確認用のオリジナルです。
3. 「歌詞・タイムライン」に歌詞・曲の長さ・BPMを入力し、「歌詞を自動配置」を押します。歌い出しと間奏をリハーサルで合わせます。`[instrumental:4]` は4小節の間奏です。
4. **LIVE**ではTAPでテンポを合わせ、「次の歌詞」「前へ」「±1拍」で補正します。**AUDIO**では音源を読み込み、LRC/SRTなどの時刻付き歌詞を音源の時刻で再生します。
5. 素材をA/Bにロードし、クロスフェーダーやAUTOで切り替えます。Cはオーバーレイです。「外部出力」で投影専用画面を開きます。
6. セットを書き出し、全曲を実際の出力機器で通します。素材は本番PCに保存し、ブラウザーのデータ消去を避けてください。

## 操作

パネル間の境界をドラッグして広さを調節できます。サムネイルのサイズ変更、「素材を広く表示」、上部「レイアウト」からの調節・リセットにも対応します。サイズはブラウザーに保存します。[画面調節の使い方](docs/browser.md#画面の広さを調節する)

| キー | 動作 |
|---|---|
| Space | 再生／一時停止 |
| T | タップテンポ |
| ←／→ | 前／次の歌詞 |
| ↑／↓ | 歌詞を1拍補正 |
| A／D | デッキA／Bへカット |
| X | AUTOクロスフェード |
| F | 映像フリーズ |
| B | 全映像・歌詞を暗転／解除 |

入力欄や設定画面ではライブ用ショートカットを止めます。ボタン・スクロール領域にフォーカスがある場合はSpace／矢印キーの標準操作を優先します。境界線の矢印キーはサイズ調節に使います。

LIVEのBPM変更は、作成時の歌詞タイムラインを基準に進行速度を変えます。AUDIOでは音源の速度を変えず、音源時刻で歌詞を表示します。歌詞・長さ・BPMだけから実際の歌唱位置を正確に特定することはできないため、自動配置は推定です。カラオケ表示の行内進行も均等割りです。

## 搭載機能

A/Bクロスフェード、Cレイヤー、5種類の合成、BPM同期、拍で予約する素材切替、類似素材選択、自動VJ、色相・彩度・拡大・回転・反転、グリッチ／ブルームなどの効果、検索・タグ・お気に入り、実映像サムネイル、セットリスト、LRC/SRT入出力、歌詞の時刻記録と位置・色・サイズ調整、マイク／ライン入力の音声反応、MIDIノート／CC／Clock、Windows版のOSC入力、暗転、フリーズ、自動保存、セットのJSON保存、無音WebM録画を備えます。

録画は256 MiBを超えた後に停止します。長時間の本番記録には外部レコーダー等を使用してください。NDI／Spout／Syphon、MTC／LTC、音声認識による歌唱解析、ワード単位の自動アラインメントは未対応です。

## 素材と利用条件

内蔵96種類は、12種類の描画方式から作った色・構図のバリエーションです。外部動画の取得状況、出典、利用条件、ハッシュ、技術情報は `assets` と `research` に保存します。**候補リストの件数と、実際にダウンロードできた動画の件数は別です。**

2026年9月9日時点で外部動画251本を取得し、243本を登録しました。[当時の素材集計](research/library-audit.json)に、ハッシュ照合、全編デコード、容量の検査結果を記録しています。9月11日にハロウィン向け実写等5本とAI生成背景のカメラループ2本を追加し、ローカルの登録動画は250本になりました。

ブラウザーには公開可能な既存118本＋新規7本、計125本を同梱（約295MB、最大720p、無音H.264）。内蔵96種類を合わせて221種類をインポート不要で選べます。公開条件が未確定の125本も、手元の `assets` を「素材管理」から接続して使用できます。[公開条件の監査](research/web-library-rights-2026.md)、[公開ファイルのハッシュ](research/web-library-build.json)、[ハロウィンの収集・生成結果](research/halloween-delivery.md)を参照してください。

[素材調査レポート](docs/material-sources.md) と素材ごとの出典を確認してください。非営利ライブでも、配布元ごとの条件は適用されます。Canvaなどのストック素材を含む `assets/media` はソースコードと一緒に再配布しないでください。

## 検証と開発

`npm test` で同期・描画の状態管理・保存データ・配信サーバーを検証します。`npm run build` で型検査と本番ビルド、`npm run build:standalone` で単一HTML、`npm run package` でWindowsポータブル版を作成します。

自動テストは実機のHDMI出力やGPUドライバー、会場設備の保証にはなりません。Surface Pro 7+およびChromebookそのものの通し運転は、利用する機器で行ってください。
