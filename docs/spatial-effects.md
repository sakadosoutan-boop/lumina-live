# 立体・奥行きエフェクト

LIVE MIXERの「沈み込む」「飛び出す」「マッピング風」で、動画・生成映像・A/B/C合成結果に即時適用できます。

- **沈み込む**：映像を重ねたフレームが縮小し、奥へ吸い込まれるように進みます。静かな展開やブレイクに。
- **飛び出す**：逆方向へ拡大し、客席へ迫るように進みます。サビやソロの盛り上がりに。
- **マッピング風**：面ごとに前面・側面・影を描き、壁面パネルがせり出したり沈んだりする表現です。

沈み込む／飛び出すは排他的な方向切替で、選択中のボタンをもう一度押すと解除できます。マッピング風は単独でも、奥行きに重ねても使用できます。「立体FX解除」はこの3系統だけを解除し、既存の色・光の設定は維持します。

**FX**を開くと、奥行きの強さ・壁面の立体感・周期（2/4/8/16/32拍、標準8拍）を調整できます。曲の拍位置を基準にするため、LIVE/AUDIOの同期方式と外部出力で同じ動きを使います。一時停止で動きが止まり、FREEZEとBLACKOUTも従来どおり機能します。歌詞は立体処理の後に重ねるため、文字は変形しません。

設定はセットファイルと端末の自動保存に含まれます。以前のセットを読み込むと新しい効果はOFFで始まります。既存の「映像プリセット」を適用すると、そのプリセットのFXに切り替わり、立体FXはOFFに戻ります。

本機能は平面スクリーンに立体感を見せる映像エフェクトです。実際の建物・箱への位置合わせ、四隅補正、投影面のマスク編集は含みません。
