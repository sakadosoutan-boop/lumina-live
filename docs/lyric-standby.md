# 映像を流したまま歌詞を待機する

LIVE・手動補正モードで使えます。

1. 「歌詞を先頭で待機」を押します。歌詞は非表示になり、曲の時計は0:00で待機します。
2. 上部の「再生」を押します。背景映像だけが進みます。待ち時間は事前に決める必要がありません。
3. 演奏開始に合わせて「歌詞スタート」を押します。映像を止めずに、歌詞のタイムラインを先頭から進めます。

イントロがある曲は、曲の開始に合わせてスタートし、作成済みのイントロ区間を使えます。歌い出しまでの時間が分からない場合は、待機したまま歌い出しで右側の該当する歌詞行をクリックできます。クリックした行から進みます。曲中は「次の歌詞」やオフセットで手動補正できます。

歌詞待機はその回の操作だけに適用され、曲の長さや保存した歌詞タイミングを書き換えません。曲の切替・セットの読込・同期方式の切替では解除されます。待機中の「停止」「先頭へ」は待機を維持します。待機中に再生位置を0以外へ動かすと解除されます。AUDIOでは従来どおり音源位置に同期します。

## BPMの入力

BPM欄を消してから数値を入力できるようにしました。Enterまたは欄の外をクリックすると反映します。20〜400、小数1桁に対応。Escで取消。空欄・無効な値を確定した場合は元のBPMを維持して案内を表示します。TAPも利用できます。
