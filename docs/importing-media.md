# Chromebookで動画を取り込む

「取り込む」から動画を選ぶと、「取り込んだ素材」に切り替わり、読み込んだ動画を先頭に表示します。再生に使う素材をクリックしてA/Bへ読み込みます。

2026-10-27修正：
- 動画の種類情報が空、または汎用形式でも、MP4 / WebM / MOV / M4V / OGVなどの拡張子で判定します。拡張子はファイル選択にも指定しました。
- 端末保存ができない場合も、ファイルを読み取れる限り、開いている画面で利用できます。その場合は画面に「次回は同じファイルを選び直してください」と表示します。
- 検索やカテゴリで取り込んだ動画が隠れないようにし、取り込み中・完了・失敗の結果を画面に残します。
- 読み取れないGoogleドライブ上の動画は、端末の「ダウンロード」に保存してから選び直してください。

取り込みとコーデック対応は別です。取り込めても再生できない動画は、MP4（H.264）またはWebMへの変換が必要な場合があります。

再生についても、フレーム通知が届かない場合の更新判定と、長い動画を短い拍数に同期させたときの連続シークを修正しました。拍数の指定がない取り込み動画は、デッキへ読み込むと通常速度・BPM SYNC OFFで開始します。既にデッキにある動画は読み込み直してください。

確認：447件の自動テストとビルド成功。種類情報なし／汎用MIME、端末保存失敗時の一時利用、古いキャッシュの復元防止、フレーム通知停止時の更新と速度上限時のシーク抑制を確認。Chromebook実機での検証は未実施。今回のブラウザファイル選択テストは検証用拡張機能のローカルファイル権限で停止し、その後の画面操作確認も接続タイムアウトで未完了です。
