# ブラウザー版の使い方

[Lumina Liveを開く](https://sakadosoutan-boop.github.io/lumina-live/)

Windows／ChromebookのChromeで上のURLを開きます。ローカルサーバーの起動は不要です。

1. 「再生」を押します。内蔵映像とデモ歌詞ですぐ試せます。
2. 「映像プリセット」で、オープニング・ロック・サビ・静かな曲・グリッチ・エンディングを選びます。映像は即時に切り替わります。
3. 個別の素材をA/Bへ読み込み、「AUTO」で拍に合わせてフェードします。
4. 「歌詞を編集」から自分の歌詞、曲の長さ、BPMを入力します。LIVEは生演奏に合わせた手動補正、AUDIOは読み込んだ音源の再生時刻による同期です。
5. 投影時は「外部出力」を開き、HDMIの拡張画面へ移動して映像をダブルクリックします。ポップアップが止められた場合は、このサイトのポップアップを許可します。

内蔵96種類と6種類のプリセットは、追加素材なしで使えます。6プリセットは内蔵映像の組み合わせなので、96本に新しい動画6本を加えた数ではありません。素材・歌詞・音源をサーバーへアップロードする機能はなく、端末内で扱います。

公開サイトには、収集済み素材から選んだ118本、ハロウィン向け7本、邦楽ロック向け4本、11曲の曲別シーン44本の計173本の無音動画を用意しています。「オンライン素材」「ハロウィン」「曲別シーン」から選べます。初回の再生には通信が必要です。内蔵生成映像と合わせて269種類です。

「素材管理」→「オンライン素材を端末に保存」で約501MBをブラウザーに保存できます。保存後は、開いている画面で通信が切れても映像を再生できます。途中で中止した場合は保存済みの続きから再開します。ブラウザーのデータ削除や空き容量不足によって再保存が必要になる場合があります。

手元の全素材を使う場合は「素材管理」→「フォルダーを接続」で、作業PCの `vj-live/assets` フォルダーを選びます。現在のカタログは254本（以前の243本＋ハロウィン7本＋邦楽ロック4本）です。動画のコピーやアップロードは行わず、名前・タグ・利用条件を引き継ぎます。次回起動時には同じフォルダーを選び直してください。Chromebookへは `assets` フォルダーをUSB等で持ち運びます。一般の動画フォルダーも接続できます。カタログを使う場合、`prepared` のみではなく `assets` を選んでください。

ハロウィンの7本は、月の回転・霧の村・霧の川2本・コウモリの熱画像と、AI生成背景によるカボチャの門／月夜の城のカメラループです。熱画像は低解像度の資料・アクセント用途です。収集した5本はシームレスループを保証しません。全素材の出典と加工内容は画面の「素材クレジット」から確認できます。

セットを「セット保存」で書き出しておくと、別端末へ持ち運べます。ブラウザー内の動画保存は端末・サイトごとに独立しており、別端末で同じURLを開いても自動転送されません。音源は再起動後に選び直します。

Surface Pro 7+では「接続・出力」の内部解像度1280×720、30 FPSから始めます。HDMIはOS側で1920×1080の拡張表示にします。操作画面は1つだけ開いてください。

## 曲の進行に合わせるシーンを準備する

1. 上部の「シーン設定」、または「セットリスト」の各曲にある「シーン設定」を押すと、画面中央に専用の設定ウィンドウが開きます。「シーンを編集する曲」で曲を選べます。編集するだけなら、再生中の曲を変えずに準備できます。
2. 「曲別素材から作成」で素材の曲を選び、「基本・A・B・Cを追加」を押すと、4本の素材を割り当てたシーンが入ります。
3. シーン名を「イントロ」「Aメロ1」「サビ2」などに変更します。名前はEnterまたは欄の外を押して確定します。素材の選択欄で変更すると、その素材の単独表示になります。
4. 複数の映像を重ねたい場合は、ミキサーで素材・速度・クロスフェード・エフェクトを作り、「現在の映像を追加保存」または「現在の映像で更新」を押します。A/B/Cの設定をまとめて保存します。
5. ↑／↓で順番を調整し、必要なら複製します。最後に「セット全体を保存」または上部の「セット保存」で書き出します。1曲につき128シーンまで登録でき、セットを開き直しても割り当てと順番が残ります。

本番は曲を「ロード」し、上部の「シーン」選択欄、または「次のシーン」で呼び出します。曲と歌詞の再生時刻は変わらず、保存した映像に即時に切り替えます。最後まで進むと「次のシーン」は無効になり、先頭へ勝手に戻りません。

設定ウィンドウは右上の「閉じる」またはEscキーで閉じます。閉じても登録済みのシーンは残ります。シーンが多い場合は設定ウィンドウの中をスクロールします。

呼び出し時には自動VJと予約中の切替を解除します。素材が未接続なら、現在の映像を維持して接続を案内します。セットファイルには動画本体は含まれないため、取り込んだ動画を別端末で使う場合は素材も再接続してください。歌詞の位置・マスター音量・暗転設定はシーンの呼び出しで変えません。

## 曲別の素材を選ぶ

左の「COLLECTIONS」にある「曲別シーン」で44本を表示できます。その下に11曲のコレクションがあり、曲名を押すとその曲の4本を表示します。検索語とメロの絞り込みは解除して開くので、前の条件で素材が隠れません。

シーンはセットリストの曲順にまとまり、各曲は「基本→Aメロ→Bメロ→Cメロ」の順に並びます。画面の横幅が狭く左のコレクションが隠れる場合は、素材一覧上部の「曲別シーン」と曲の選択欄を使えます。

## 歌詞の表示位置を調節する

「LYRICS」の「表示位置」を押します。左上・上中央・右上・左中央・中央・右中央・左下・下中央・右下の9か所から選べます。「横位置（左→右）」「縦位置（上→下）」のスライダーで、さらに細かく移動できます。

変更は投影画面と録画にも反映され、セット保存に含まれます。「位置を初期値に戻す」で下側の中央に戻せます。長い歌詞や大きい文字は、画面の外へ切れないよう位置が調整されます。

## 画面の広さを調節する

- 素材一覧の「サムネイル」スライダーで、画像を大きく／小さく表示します。
- 「素材を広く表示」でプレビューとミキサーを一時的に隠し、素材を選ぶ領域を広げます。「プレビューを戻す」で元に戻ります。投影中の映像は止まりません。
- パネル間の境界線をドラッグすると、サイドバー・歌詞・プレビューとミキサーの幅、プレビューと素材一覧の高さ、タイムラインの高さを調節できます。境界にフォーカスして矢印キーでも調節でき、ダブルクリックまたはEnterでその境界を標準に戻します。
- 上部の「レイアウト」からも調節でき、「標準レイアウトに戻す」で全体を戻せます。サイズ設定は端末・ブラウザー・URLごとに保存され、セットファイルには含まれません。
- 小さなウィンドウではパネルを縦に並べます。素材・歌詞・セットリストへの切り替えは上部のタブから行えます。

素材一覧・ミキサー・歌詞はそれぞれのスクロールバーで移動します。パネルにフォーカスがあるときの矢印キー／Spaceはスクロール・選択を優先します。入力欄や設定画面の操作中はライブ用ショートカットを実行しません。

オフラインで開く場合は[単一HTML](https://github.com/sakadosoutan-boop/lumina-live/blob/main/web/Lumina-Live.html)を「Download raw file」で保存してChromeで開きます。HTTPS版とは保存領域が異なります。オンライン版のページを閉じて通信も切った場合に、自動でオフライン起動する仕組みはありません。

オンライン版と単一HTMLは保存領域が異なるため、単一HTMLで使う動画はフォルダーを接続し直します。HTTPS側で保存した動画がHTMLへ自動転送されるわけではありません。
