# 邦楽ロックの素材セット

「邦楽ロック」から選び、用途ボタンで絞り込めます。曲名や既存MVを使わない、複数の曲に組み合わせられる背景です。

| 新規オリジナル | 使いどころ |
| --- | --- |
| 放課後の空 | 青春感、静かなAメロ、長い余韻。夕焼けと街のシルエット |
| 雨のミッドナイト | 夜や孤独を感じる曲、暗めのAメロ。赤と青の雨の街 |
| 夜明けの海岸線 | 開放的なサビ、前向きな終盤。海へ続く道と朝焼け |
| PRISM IMPACT | 力強いサビ、間奏。赤・青の抽象的な光とガラス |

4本とも16秒・1280×720・30fps・無音H.264です。AI生成した静止画に周期的なカメラ移動を加え、PRISM IMPACTには滑らかな光量変化も加えました。街や波が個別に動く映像ではありません。BPM SYNCを使うと、指定した拍数に合わせて再生速度が変わります。

Aに静かな風景、Bに抽象的な動きのある映像を置き、サビの頭で「AUTO 4拍」または「CUT B」で切り替えると使いやすくなります。歌詞が背景に埋もれる場合は、映像の明るさを下げ、歌詞の影を有効にしてください。全曲を実際の歌詞とプロジェクターで確認して調整します。

既存の公開動画からも邦楽ロック向けの素材を選び、Aメロ・サビ・夜／緊張感・余韻のタグを付けています。[選定と用途](../research/jrock-selection-guide.md)。選定した既存素材は追加のダウンロード件数には数えません。
