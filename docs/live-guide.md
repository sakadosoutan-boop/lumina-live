# LUMINA LIVE — バンドライブ操作ガイド

非営利バンドの生演奏と伴奏音源のどちらでも使うためのガイド。操作用画面と、HDMIの1920×1080プロジェクター1台への投影を想定する。最初は内部1280×720・30 FPSで準備し、Surface Pro 7+または使用するChromebookで通しリハーサルを行う。特定機種でのGPU性能、1080p／60 FPSの安定動作は認証されていない。

内蔵96種類はその場で描くオリジナルGPU映像。外部素材の取得・収録数は変動するため、[素材の出典と取得状況](../docs/material-sources.md)を参照する。

## 起動とHDMI出力

Windowsのソース一式からは[start-windows.cmd](../scripts/start-windows.cmd)を起動する。配布用のportable EXEが存在する場合はそれを優先する仕組みがあり、EXE単体の実行にはNode.jsは不要。ソース実行には依存関係とビルドが必要になる。確認時点では配布用releaseフォルダーの存在をまだ確認できていないため、この記述をEXE配布完了の証拠にはしない。[ビルド設定](../package.json)

Chromebookはブラウザー版を使用する。単体オフラインHTMLを作る[ビルド処理](../scripts/build-standalone.mjs)があり、生成されたHTMLを端末に保存してChromeで開く方式を想定する。HTMLには内蔵映像・アプリ処理をまとめるが、外部動画ライブラリを丸ごと埋め込まない。確認時点ではその生成物は未確認。管理対象Chromebookではファイルを開く操作、外部出力、MIDI、マイク、ストレージの利用可否を実際のアカウントで確かめる。

ソースからローカル配信する場合は、依存関係が準備済みのプロジェクトで次を使う。既にビルド済みならserveだけでよい。

```powershell
Set-Location -LiteralPath 'C:\Users\masuk\OneDrive\デスクトップ\Codex作業場\vj-live'
npm run build
npm run serve
```

表示されたlocalhostのURLを開き、サーバーのターミナルを開いたままにする。ポート使用中は別のポートになる場合がある。ブラウザー版のこのローカルサーバーにはOSC受信機能はない。[配信スクリプト](../scripts/serve.mjs)

1. HDMIを接続し、OS側で画面を拡張する。外部側の解像度を1920×1080に設定する。
2. LUMINA LIVEの「接続・出力」で内部解像度1280×720、30 FPSから始める。外部信号が1080pでも内部720pを拡大して表示できる。
3. 「外部出力」を開く。Windows版は外部画面を選択でき、ブラウザー版は別ウィンドウを投影先へ移動して映像をダブルクリックで全画面にする。ポップアップが拒否された場合は許可設定を確認する。
4. 操作画面を手元に残し、投影側に操作UIが写っていないことを確認する。
5. 音源を使う場合はPAへ送るOSの音声出力先も確認する。HDMI接続により音声がプロジェクターへ向かっていないか、実際に再生して確かめる。

ブラウザー版の入力APIには権限や対応差がある。localhost・対応するローカルファイル等の安全なコンテキストが必要で、単にLAN内のHTTPサーバーを開くだけでは使えない場合がある。[マイク等の権限](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[Web MIDI](https://developer.mozilla.org/en-US/docs/Web/API/Web_MIDI_API)

## 素材を選び、重ねる

ライブラリで対象のデッキをA／B／Cから選んで素材をクリックする。AとBはクロスフェーダーで切り替え、Cは上に重ねる映像。Cの初期不透明度は0なので、重ねる場合は必要な量まで上げる。

| 操作 | 動作 |
| --- | --- |
| CUT A／CUT B | フェーダーをA側／B側へ即座に移動。 |
| AUTO | 指定した1・2・4・8・16拍の長さで反対側へフェード。 |
| 素材切替クオンタイズ | 停止中は即時。再生中は即時、次の拍、次の4拍、次の8拍から選択。4拍は固定の拍数で、3拍子の1小節という意味ではない。 |
| BPM SYNC＋ループ拍数 | 動画1周を指定拍数へ合わせるよう速度・位置を補正。元動画を継ぎ目のない動画に作り直す機能ではない。 |
| デッキ設定 | 不透明度、速度、拡大、回転、反転、色相、彩度、明るさ、ブレンド。 |
| FX | glitch、bloom、vignette、chromatic、pixelate。 |
| AUTO VJ | 2・4・8・16小節ごとに候補を選び、切り替える。演出の適否はリハーサルで確認。 |
| MASTER OUT | 合成映像の出力レベル。伴奏音源の音量フェーダーではない。 |

「類似素材」はタグ・登録されたenergy・hueを使う。動画全編をAI解析して意味を理解する仕組みではなく、取得動画の値には仮の中立値もある。選択候補が音楽に合うかは担当者が判断する。

動画レイヤーは消音して描画する。伴奏を再生する場合は「同期用音源を読み込む」から別途読み込む。形式・コーデックは端末のデコーダーに依存するため、MP4という拡張子だけでは再生を保証できない。問題が出る素材は本番前に実際の端末で代替素材へ置き換える。

## 歌詞を準備する

1. 曲を選び、BPM、曲の長さ、拍子を設定する。音源がある場合は先に読み込み、取得された実際の曲尺を確認する。
2. 歌詞欄へ1行につき1キューで入力する。独立した行の `[instrumental:4]` は4小節の間奏として扱う。
3. 「歌詞を自動配置」を押す。文字量に応じて時間を配分し、小節境界へ寄せる粗い推定が作られる。
4. リハーサルに合わせて「今を記録」、開始秒・終了秒を編集する。右側の「記録」モードでも該当行を押した時刻を記録できる。
5. 歌い出し、間奏、繰り返し、最後に歌詞が消える時刻を確認し、セットとLRC／SRTを保存する。

自動配置は音源解析・歌声認識ではない。音節数やメロディー、休符、歌い伸ばしを知ることはできない。間奏の指定時間が曲尺に収まらない場合は推定全体が縮められることもある。既に調整した後で再度自動配置すると、その曲のキューが推定値に置き換わり、オフセットも0に戻るため、調整済みセットを先に保存する。

LRC／SRTを持っている場合は「LRC / SRT」で読み込む。LRCの最後の終了時刻は次の境界がなければ5秒後という推定なので、曲末を確認する。SRTは開始・終了区間を持つ。重複区間や空白区間は編集画面で確認し、長い行は客席から読める長さへ分ける。例：

```text
[00:12.00]歌い出しの一行
[00:18.50]次の一行
[00:24.00]
```

これはLRCの例で、最後の空行時刻が直前の行の終了境界になる。保存したLRC／SRTはキュー時刻の書き出しで、実演中に調整した曲全体のオフセットまで焼き込む保存ではない。オフセットを含めて戻すにはセットJSONも保存する。[歌詞処理の根拠](../src/sync.ts)、[画面操作](../src/App.tsx)

## 生演奏に合わせる：LIVE

「LIVE」を選び、演奏開始に合わせて再生する。テンポはTキーのタップ、BPM入力、または設定で有効にしたMIDI Clockから変更する。マイク音を聞いて自動でBPMや歌唱位置を追いかける機能ではない。

基準BPMで作った歌詞タイムラインは保存したtimelineBpmを基準に進む。例えば120 BPMで配置したキューをLIVEで132 BPMにすると、タイムラインは1.1倍の速度で進む。既存の歌詞時刻を逐一書き換える方式ではなく、時間の進み方を変える。保存・再読込後も基準BPMを維持する。[ライブ時計](../src/live-clock.ts)

歌い出しがずれたら「次の歌詞」「前へ」または目的のキューを押す。LIVEでは曲の再生位置を動かさず、歌詞のオフセットを調整する。↑／↓は歌詞を1拍分進める／戻す。正のオフセットは歌詞を先へ進め、負は遅らせる。曲の位置を変えたい場合は下のタイムラインを操作する。

マイク／ライン入力は低域・中域・高域などのレベルを映像反応に使う。歌唱内容を認識しない。入力を有効にすると伴奏用の音声エンジンを置き換えてLIVEに切り替えるため、同じアプリで伴奏再生と別マイク解析を同時に使う前提にしない。[音声入力実装](../src/audio.ts)

## 伴奏音源に合わせる：AUDIO

「同期用音源を読み込む」から手元の音声を読み込むとAUDIOへ切り替わる。音源の再生時刻が歌詞の基準になる。固定の伴奏とLRC／SRT、またはその伴奏で調整したキューを合わせて使う。

**AUDIOで「次の歌詞」「前へ」やキューを押すと、伴奏音源の再生位置も移動する。** 本番で音源を途切れさせず歌詞だけを補正したいときは、歌詞オフセットを調整する。BPM変更は映像の拍同期に使われ、音源の再生速度やピッチは変えない。

曲の切替・セットの読込は再生を停止する。音声データはセットJSONに埋め込まれておらず、曲を切り替えたり再起動したりした後は必要な音源を再度読み込む。全曲分の伴奏が自動で連続ロードされると想定しない。LIVE／AUDIOを切り替えると一時停止するので、位置を確認して再生する。

## キーボード

操作画面にフォーカスを戻して使う。文字入力欄、選択欄などにフォーカスがある間はショートカットを処理しない。Bが効かない場合は操作画面のBLACKOUTボタンを使う。

| キー | 動作 |
| --- | --- |
| Space | 再生／一時停止 |
| T | タップテンポ |
| ←／→ | 前／次の歌詞。AUDIOでは音源もシーク |
| ↑／↓ | 歌詞オフセットを＋1拍／−1拍 |
| A／D | A／Bへカット |
| X | AUTOクロスフェード |
| F | 合成映像をフリーズ／解除 |
| B | 全映像を暗転／解除 |
| ? | 操作ヘルプ |
| Escape | 操作画面の設定を閉じる。Windowsの投影ウィンドウでは出力を閉じる |

BLACKOUTは映像を黒くし、FREEZEは表示フレームを保持する。いずれも伴奏のミュート・停止ではなく、曲の進行自体は続く。演奏を止める際は停止操作とPAの音量を別途扱う。

## MIDI

「接続・出力」→「MIDIを接続」を押し、ブラウザーに要求された場合は接続権限を許可する。受信する入力機器と以下の固定マッピングを使う。実装は通常MIDIで、SysExは要求しない。

| 入力 | 動作 |
| --- | --- |
| Note 36／37 | 次／前の歌詞 |
| Note 38 | TAP |
| Note 39 | 暗転切替 |
| Note 40 | 再生開始。一時停止とのトグルではない |
| Note 41／42 | AUTO／FREEZE |
| Note 48〜55 | ライブラリ全体の先頭8素材。現在の検索結果や表示ページの8素材ではない |
| CC 1／CC 7 | クロスフェーダー／映像MASTER。0〜127を0〜1へ変換 |
| Clock | 「MIDI ClockからBPMを受信」有効時にBPMへ反映 |
| Start／Continue／Stop | 先頭から開始／継続／一時停止 |

Note Onはvelocityが0より大きい場合に反応する。MIDI ClockからBPMを受ける機能と、SMPTE等の絶対時刻で合わせるMTCは異なる。MTC・LTCは対応していない。[受信実装](../src/audio.ts)

## OSC

Windowsデスクトップ版だけがUDP **127.0.0.1:9000**で受信する。同じPC内の送信アプリ用で、スマートフォンや別PCからLAN越しに直接接続する受信先ではない。ポートが使用中ならOSCなしで継続する。

| アドレス | 引数・意味 |
| --- | --- |
| /lumina/play | 引数なしで再生開始 |
| /lumina/stop | 引数なしで一時停止。先頭へ戻す命令ではない |
| /lumina/next、/lumina/prev | 引数なしで次／前の歌詞 |
| /lumina/tap | 引数なしでタップ |
| /lumina/blackout | 引数なしで切替、整数またはfloatの0／1で解除／暗転 |
| /lumina/crossfade、/lumina/master | 0〜1の数値1個 |
| /lumina/clip | 整数1個、0始まりのライブラリ全体インデックス。存在する素材を指定 |

通常のOSCメッセージのみを扱う。bundle、文字列、timetag、パターン、任意のOSCアドレスは対象外。起動時の `--no-osc` または `LUMINA_OSC=0` で無効化できる。[OSCサーバー](../desktop/server.cjs)、[Windows起動処理](../desktop/main.cjs)

## カメラ・レイヤー・録画

A/B/Cの動画・画像・内蔵映像を合成できるが、**現在のコードにはカメラ入力がない**。マイク入力の許可はカメラ許可ではなく、Windows版も音声のみを許可する。カメラ、USBキャプチャ、NDI、Spoutの映像を取り込めると想定しない。

PROGRAM MONITORのRECで合成映像を録画し、STOP RECでWebMへ書き出す。記録するのは操作側の合成canvasで、A/B/Cや歌詞が合成された映像。各レイヤーを別ファイルにしたり、HDMIの出力信号そのものをキャプチャしたりする機能ではない。

- **音声は録音しない。** 伴奏もマイクもWebMには入らない。
- UIの「256MB」はコード上 **268,435,456 byte（256 MiB）**。1秒単位の受信チャンクで超えた時点に停止するため、厳密にそのサイズ以下になる保証はない。
- 停止後にファイルを保存し、必要ならRECをもう一度押す。自動で次の録画へ連続分割する機能ではない。
- 内部解像度・設定FPSで記録し、録画負荷が加わる。長時間のライブ全体を常時録画できると想定しない。

録画形式はMediaRecorderで対応するWebM方式を選ぶため、実際の端末で録画・保存・再生を確認する。[録画実装](../src/App.tsx)、[MediaRecorderの形式対応](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder)

## 保存・オフライン・持ち運び

セット保存では曲、歌詞キュー、BPMと基準BPM、オフセット、素材参照、デッキ、映像効果などをJSONへ書き出す。画面上の自動保存は同じ環境のブラウザーストレージへの保存で、外部バックアップではない。曲の音声そのものは含まれない。内部解像度・FPS・LIVE／AUDIO選択など、一部の運用設定もセットに含まれないので起動後に確認する。

| 環境 | 素材の保持 | 移行・復元時の注意 |
| --- | --- | --- |
| Windowsデスクトップ | インポートした元ファイルを登録して参照 | 元ファイルを移動・削除しない。セットだけ別PCへ渡しても映像は移らない。 |
| ブラウザー | インポートした動画・画像をIndexedDBへコピー | 同じブラウザー・プロファイル・originに依存。履歴／サイトデータ削除や容量制限で失われる場合がある。 |
| 外部の素材カタログ | 配布・登録されたファイルを参照 | そのファイル群がローカルに必要。候補JSONだけで映像は復元しない。 |
| 伴奏音源 | セッション中に読み込む | JSONには名前を保持するが、再起動・曲変更後は再リンクする。 |

素材が欠落したときは正しいファイルを再度取り込み、デッキへの割当を確認する。権利のある原本とセットJSON、歌詞ファイル、伴奏音源を別の保存先にも保持しておく。ブラウザーに複製する場合は元ファイルとコピーの両方が容量を使う。20,000,000,000 byteの素材上限は全保存先・展開途中も含めて管理する。[保存実装](../src/storage.ts)

オフラインで使うにはアプリと使用素材を全て端末に保存しておく。Canva／VideoZeroのプロジェクトURLを開けるだけでは、オフライン再生用素材を確保したことにならない。事前にネット接続を切った状態で起動、素材ロード、歌詞表示、保存・再読込を試す。

## 本番前の確認と困ったとき

親側の検証結果として、346件のテストとビルド成功、CUAによる投影画面・歌詞・BLACKOUTの確認が報告されている（2026-09-09 JSTの引継ぎ）。この文書担当による再実行結果ではなく、使用するSurface／Chromebookと実プロジェクターでの検証を代替しない。

| 確認・症状 | 行うこと |
| --- | --- |
| 映像が出ない | 出力先、拡張表示、BLACKOUT、MASTER、デッキ不透明度、Cの状態、素材ロードを確認。 |
| 映像が重い | 内部720p・30 FPSから確認し、必要なら540pへ下げる。FX、重ね数、録画を減らす。内部解像度を下げても高解像度動画のデコード負荷は残る。 |
| 歌詞がずれる | LIVEかAUDIOかを確認し、歌い出しと間奏を記録。テンポ変更だけで全フレーズが正確になるとは限らない。 |
| 伴奏が飛ぶ | AUDIOで歌詞キューを押すとシークする。歌詞だけの補正はオフセットを使う。 |
| 音が聞こえない | OSとPAの音声経路、AUDIOモード、読み込み済み音源を確認。映像MASTERでは音量は直らない。 |
| キーが効かない | 操作画面へ戻り、入力欄の編集を終了。急ぐ場合は画面のボタンを押す。 |
| 保存後に素材がない | 元ファイル・IndexedDB・プロファイルの状態を確認し、再インポートして割当を確認。 |
| 録画が止まる | サイズ上限と保存結果を確認。必要なら手動で次を開始。 |

全曲を実際の構成で通し、歌詞の可読性、A/B/C切替、暗転からの復帰、音源出力、停止・再開、保存・再起動を確認する。FPSやlateはその実行中の目安であり、HDMIの信号品質やGPUの性能保証ではない。MTC／LTC／NDI／Spout、AIボーカルASR、単語・音素単位の正確な歌詞位置合わせは未対応。カラオケ表示の行内進行は時間を均等に割った表現であり、実際の発音に合わせた単語ハイライトではない。

実装照合基準：2026-09-09 00:10 JST前後。[操作実装](../src/App.tsx)、[描画実装](../src/renderer.ts)。共有作業中のため、親側の最終監査で配布物・カタログ・カメラ機能・保存方法に変更があればこのガイドも更新する。
